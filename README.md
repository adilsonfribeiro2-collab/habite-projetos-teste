# Habite · projetos de teste

Repositório **privado** com projetos reais usados só para testar a leitura de projetos (A3) e as plantas simplificadas (C0 e C) do Habite.

## Regras (decisão 70 do Master Plan)

- Uso autorizado pelas empresas **apenas para teste interno**.
- Nada daqui vai para demonstração, site, landing, material de venda ou manual entregue a terceiros.
- Nada daqui é copiado para o repositório `habite`. Lá ficam só o código e os testes com empreendimentos fictícios; os testes com estes projetos leem esta pasta quando ela existe.
- Se uma empresa pedir a retirada, apaga-se este repositório inteiro, sem tocar no `habite`.

## Como enviar arquivos pelo navegador

1. Abra a pasta de destino no GitHub (ex.: `empreendimento-1/arquitetura/dwg`).
2. **Add file → Upload files**, arraste os arquivos e clique em **Commit changes**.
3. Limite do navegador: 25 MB por arquivo e até 100 arquivos por vez. Arquivo maior: divida o zip ou mande pelo chat do Claude.
